### Camera App
- Capture image using Camera X library
- Splash API for Splash Screen along with Brand Image and Brand Name
- Adaptive Icon (Theme based App Icon)
- Jetpack Compose Navigation
- Hilt for Dependency Injection
- MVVM Architecture
- Room Database for store the image related content
- Coil for Image loading
- Coil for apply different transformations on the image

  ### Different transformations are as below
  - Rounded Corner Transformation
  - Circle Crop Transformation
  - Sqaure Crop Transformation
  - Blur Transformation
  - Gray Scale Transformation
  - Color Filter Transformation
  - Mask Transformation
