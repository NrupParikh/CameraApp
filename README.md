# Camera App with Jetpack Compose

Welcome to the Camera App built with the power of Kotlin Jetpack Compose! This app allows you to capture stunning images using the Camera X library while offering a sleek and intuitive user experience.

## Features

- **Camera X Integration**: Capture high-quality images seamlessly with the Camera X library.
- **Splash API Integration**: Engage users right from the start with a captivating Splash Screen featuring your brand image and name.
- **Adaptive Icon Support**: Make your app stand out with adaptive icons that adapt to various themes.
- **Jetpack Compose Navigation**: Navigate through the app effortlessly with the power of Jetpack Compose.
- **Hilt for Dependency Injection**: Ensure clean and maintainable code with Hilt for dependency injection.
- **MVVM Architecture**: Keep your codebase organized and scalable with the Model-View-ViewModel architecture pattern.
- **Room Database**: Store image-related content securely and efficiently using Room Database.
- **Coil Image Loading**: Load images effortlessly and efficiently with Coil.
- **Image Transformations**: Customize your images with a variety of transformations, including:
  - Rounded Corner Transformation
  - Circle Crop Transformation
  - Square Crop Transformation
  - Blur Transformation
  - Gray Scale Transformation
  - Color Filter Transformation
  - Mask Transformation

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on your device or emulator.

That's it! You're ready to explore the world of stunning image capture and transformation with our Camera App powered by Jetpack Compose.
